# 🎓 Udemy Clone Website

A responsive Udemy Clone website built using HTML and CSS. This project recreates the modern UI of the Udemy online learning platform with a clean design, course sections, and responsive layout.

## 🚀 Features
- Responsive homepage design
- Modern navigation bar
- Course cards and categories section
- Clean and user-friendly UI
- Mobile-friendly layout
- Built using pure HTML & CSS

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- Flexgrid

## 📂 Project Purpose
This project was created to practice front-end web development skills and improve responsive website design using HTML and CSS.
